# SynoPixtri

Community photo and video sorting app for Synology NAS, driven from a web interface instead of a command line.

> Work in progress. This project is not affiliated with or endorsed by Synology Inc.

## Goal

Sort a personal photo library (dates, GPS, Live Photos, events, stays, duplicates) directly from a NAS, with a UI to review and validate what gets moved.

## Origin

The sorting engine comes from an earlier Python CLI that targeted a Raspberry Pi (DietPi). It is archived, unchanged, on the [`raspberry`](../../tree/raspberry) branch.

## Status

Design phase. Nothing usable yet.
